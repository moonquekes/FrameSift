# 拾帧 FrameSift · 海量存储版

FrameSift 是一款 Android 相机照片浏览与导入工具。通过 USB 连接相机，在手机上按拍摄日期浏览 JPEG、
筛选照片，再将选中的原始文件导入手机图库，无需先复制整张存储卡。

本分支使用 **USB 海量存储（MSC / Mass Storage）**，由 Android 挂载相机存储，通过用户授权的照片目录读取文件。
适用范围取决于相机的 USB 模式和手机的存储访问能力，不限定相机或手机品牌。

## 适用条件

- **手机**：Android 7.0（API 24）及以上，支持 USB Host/OTG。当前 APK 包含 ARM64 和 ARMv7 原生库。
- **相机**：能够通过 USB 海量存储模式将照片所在的存储卡或存储卷提供给手机。
- **系统访问**：Android 能识别并挂载该存储卷及其文件系统，系统文件夹选择器能够打开照片目录并授予访问权限。
- **连接线**：使用支持数据传输的线缆及所需的 OTG 转接设备。
- **照片格式**：当前相机相册仅浏览和导入 JPEG，不提供 RAW 或视频的相册浏览与导入。

系统能够挂载存储卷是前提；应用不提供底层磁盘或文件系统驱动。不同 JPEG 的 EXIF 缩略图、
MPF 内嵌预览及不同手机的文件读取实现可能影响预览功能，满足上述条件不等于所有功能均已完成兼容性验证。

## 开始使用

1. 下载并安装 `framesift-mass-debug.apk`，或按[构建说明](docs/BUILD.md)自行构建。
2. 按相机说明将 USB 连接方式设为「海量存储器 / Mass Storage / MSC」。如有互斥的遥控或手机连接模式，先关闭这些模式，
   再用数据线连接手机。不同品牌和型号的菜单名称可能不同。
3. 打开应用，点「选择相机照片文件夹」。在系统文件夹选择器中找到相机存储，选择照片所在目录，通常是 `DCIM`，
   再点「使用这个文件夹」并允许。当前安装包的应用名称仍显示为 **PhotoSync**。
4. 允许应用请求的原始照片元数据访问权限。Android 10 及以上的原图导入需要 `ACCESS_MEDIA_LOCATION` 权限，
   用于保留 JPEG 中已有的 EXIF 定位字段；相机源目录仅以只读方式访问。
5. 点按照片查看大图，长按进入多选。点导入后可查看读取、保存和完整性校验进度。
   原始 JPEG 保存到手机图库的 `Pictures/PhotoSync`。

## 照片目录如何定位

1. 应用查找 Android 已挂载的可移动存储卷，不根据相机型号拼接固定文件路径。
2. 首次打开目录选择器时，尝试定位到一个已挂载存储卷的 `DCIM`。这只是初始位置，实际扫描范围由用户选择的目录决定。
3. 应用递归扫描该目录及其子目录，按 `.jpg`、`.jpeg` 扩展名筛选文件，忽略大小写。
   不要求照片子目录或文件采用特定品牌的命名规则。
4. 每张照片使用系统提供的文档 URI 定位和读取。拍摄日期等元数据另从 JPEG 文件头读取。
5. 目录只读授权会被持久保存。重新连接同一存储卷且授权仍有效时，可以复用原目录；
   换卡、格式化导致卷标识改变，或授权失效时，可能需要重新选择。

同时存在多个可移动存储卷时，需要在系统选择器中确认所选目录确实属于目标相机。
当前目录访问仅接受 Android 系统外部存储文档提供器；目录递归深度上限为 8 层。

## 挑片方式

- 相册只显示 JPEG，按拍摄日期分组，默认最新优先。日期组可以折叠和整组选中。
- 普通翻阅优先使用 JPEG 内嵌缩略图和支持的 MPF 中图，减少完整原图读取。放大到中图像素不足、主动查看原图或导入时，
  按需读取完整 JPEG。松手切换原图时保留当前倍率和画面中心。
- 大图 EXIF 默认显示焦距、镜头、ISO、光圈和快门，可在「拍摄参数」中调整显示字段。
- 「连拍分组」使用时间和文件序号启发式规则。默认要求相邻间隔不超过 1 秒、至少 3 张且 `DSC` 序号连续。
  对其他文件命名方式，可以关闭连续序号要求；分组结果是连拍候选，不是相机提供的确定连拍标记。
- 新拍的照片可通过刷新或重新连接加入列表。
- 导入按原文件复制，不重新编码 JPEG，并核对 SHA-256。
