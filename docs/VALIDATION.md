# 海量存储真机验证

| 项目 | 验证结果 |
| --- | --- |
| 设备 | Sony ZV-E10 一代、荣耀 Magic7（Android 17 / API 37）、exFAT SD 卡。 |
| 索引和连接 | 1,316 张 JPEG 的文件名、大小、拍摄时间与 MTP 对照一致。首次完整索引约 33–39 秒，复用约 1 秒。实际拔插一次，目录授权保留，荣耀图库未弹 USB 授权。 |

| 构建 | `assembleDebug`、`testDebugUnitTest`、`lintDebug` 通过，81 项单元测试，Lint 0 错误。 |
